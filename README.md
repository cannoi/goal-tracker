# Goal Tracker

A personal goal-management application designed to help you create goals, organize them by category, break them into manageable milestones, and track progress visually.

## Features
- Create, edit, archive, and delete personal goals.
- Assign goals to categories with custom colors.
- Set optional target completion dates.
- Break goals down into step-by-step milestones with automatic progress calculation.
- Dashboard summarizing active goals, completed goals, and overall milestone progress.

## SoloHost Deployment
This application is packaged as a SoloHost-compatible service with persistent SQLite storage.
